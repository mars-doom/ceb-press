The Machine — The Splitter IS the Press

  • The insight: a log splitter is already a horizontal hydraulic press — I-beam + cylinder + engine-driven power pack in one unit
  • The build: mold bolts horizontally on the beam end; cylinder pushes the platen through the bore. No press frame purchased, none fabricated
  • Force: system ~3,000 psi × stock ~5″ bore = ~25T → 8×10=625 psi, 6×12=694, 10×10 paver=500 — all in band
  • Cost: splitter $350 + mold plate ~$110 + parts → ~$460–635 — one machine, one purchase
  • Bonus: fully reversible — splitter still splits logs
  • Tradeoff: brick sized to stock force (8×10 = 625 psi ✓) — no swap, no beam mod; ~18 lb units handle easy

Hydraulics — One Line

  • Two-stage pump = fast approach + slow squeeze, free
  • Face pressure @stock 25T: 625 @8×10 · 694 @6×12 · 500 @paver — all in the 500–1,500 band
  • Altitude ~7,500 ft → ~20% derate → slower cycle, sized OK

Soil Gates — Test Before You Commit

  • 1. Test hole ~3–4 ft, watch 24–48h — seep = shallow sink or pad (SLV water table)
  • 2. Jar test — 15–30% clay target; SLV sandy → +5–10% native soil only — crush gate decides
  • 3. Soak/efflorescence test — salt-weak soil fails the 24-hr soak directly (Salton)
  • 4. Selenium — Salton ag-drain history → cheap lab screen
  • 5. Native moisture 4–6% — weigh→dry→reweigh; dig-fresh spoil carries it
  • 6. Bearing walk — tamp, walk it; pumping/prints = rethink siting
  • 7. Pressed validation — waist-high drop survives; 24h soak; SLV freeze-thaw cycle
  • Bone-dry <3% → mist liters/ton only (still ~zero-water)

Production Line — Press at the Pit Edge

Dig pit→Sieve→Tarp-mix (±native soil only — crush gate decides→ Dose scoop→Press + dwell→Door drops→ Slide to stack→Carry to wall
  • ~30–60 s/cycle → 1–2 bricks/min
  • ~2,100 units/dome ≈ 10–21 press-hours
  • Excavation = soil source — spoil never leaves the site
  • Fines → mix · coarse sand → drainage · rest → berm
  • ~18 lb units — one-person stacking, ground-row curing at wall height
  • QC loop: gauge every cycle · thickness/flatness every 20th · drop test every 50th · key-fit every batch
  • The press IS the crush rig — gauge at failure = MPa

Water Defense — 7 Layers, All On-Site

  • 1 Siting — highest ground, never in a "dry" wash
  • 2 Diversion swale — contour ditch around both sides; spoil = levee; doubles as permaculture water harvest
  • 3 Rim collar 12–18″ — floor below grade, springline above — sheet flow can't climb in
  • 4 Flared apron — kills splash/ponding
  • 5 Air-gap lining — 1–2″ void behind wall (better than rubble, zero material) + drain channel to daylight
  • 6 Covered entry — stomion vault — corbelled vault roofs the inner stair run through the berm: doorway never sky-exposed; open outer run → drain sump; raised sill lip at door
  • 7 Infiltration floor — loose pavers + coarse sand
  • Residual: catastrophic flood → ~free soil + 3 days = rebuildable by design
